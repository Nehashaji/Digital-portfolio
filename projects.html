Weather Condition Recognition

CNN & Transfer Learning • Python • TensorFlow • Gradio

Python TensorFlow CNN MobileNetV2 Transfer Learning Gradio Data Preprocessing

Project Overview

Developed a computer vision system to automatically classify weather conditions from images into four categories: Cloudy, Rainy, Shine, and Sunrise. The project demonstrates end-to-end workflow from dataset preprocessing, model training, evaluation, to interactive deployment, showcasing practical AI application skills.

Problem & Objectives

  • Automate detection of weather conditions from outdoor images
  • Handle visually similar categories and small dataset limitations
  • Leverage transfer learning to improve accuracy
  • Deploy an interactive, user-friendly interface for real-time predictions

Dataset & Preprocessing

  • Kaggle multi-class weather image dataset
  • 4 labeled classes: Cloudy, Rainy, Shine, Sunrise
  • Image resizing, normalization, and pixel value scaling
  • Data augmentation: rotation, flipping, zoom for robustness
  • Training/validation split with stratification for class balance

Model Development & Implementation

  • Built a baseline CNN to benchmark performance
  • Applied transfer learning with MobileNetV2 (ImageNet pretrained)
  • Trained custom classification layers while freezing base layers initially
  • Fine-tuned deeper convolutional layers with reduced learning rate
  • Hyperparameter experimentation: batch size, dropout, learning rate scheduling

Evaluation & Results

  • Monitored performance using accuracy, loss curves, and confusion matrix
  • Calculated Precision, Recall, and F1-Score for each class
  • The final MobileNetV2 model achieved ~87% validation accuracy and improved classification performance compared to the baseline CNN.
  • Some confusion between Shine and Cloudy, highlighting dataset challenges
  • Implemented iterative improvements based on evaluation insights

Deployment & Application

Deployed the trained model with a Gradio interface allowing users to upload weather images and receive real-time predictions with confidence scores. This demonstrates full-stack deployment skills and user-oriented AI applications.

Key Learning & Skills Demonstrated

  • End-to-end computer vision project development from dataset preprocessing to deployment
  • Practical experience in CNNs, transfer learning, and fine-tuning pretrained models
  • Model evaluation using metrics and confusion matrix for actionable insights
  • Data augmentation techniques to improve model generalization
  • Deployment of machine learning models with interactive user interfaces
  • Problem-solving for small datasets, visually similar classes, and performance optimization

Reflection

This project strengthened my ability to apply deep learning to real-world problems, enhanced my understanding of model evaluation, and demonstrated how to deliver functional AI solutions that are both accurate and user-friendly. I learned to balance technical implementation with usability and performance optimization.

Academic Genie - AI Study Planning Chatbot

Conversational AI • NLP • Google Dialogflow • Intent Recognition

Google Dialogflow Conversational AI NLP Intent Recognition Entities Slot Filling Context Management Custom Payloads Chatbot UX

Project Overview

Developed Academic Genie, an AI-powered chatbot that helps students create personalized study plans based on their subject, academic challenges, available study time, and motivation. The chatbot combines conversational AI, visual study plans, and supportive responses to create an engaging study-planning experience.

Problem & Objectives

  • Help students organize and manage their academic workload
  • Provide personalized study guidance based on individual needs
  • Make study planning more engaging through conversational interaction
  • Provide visual study plans for different academic subjects

Conversational Design

Designed a structured dialogue flow that guides users from an initial greeting through information gathering and personalized study-plan generation.

  • Created intents for subject selection, challenges, motivation, and study time
  • Implemented restart, exit, welcome, and fallback intents
  • Created subject-specific flows for Math, Science, Programming, English, and History
  • Added small-talk responses and interactive response chips

Entities, Slot Filling & Context

Used entities, slots, and context variables to collect user information and maintain conversation state throughout the interaction.

  • @subject - Selected academic subject
  • @challenge - Main academic difficulty
  • @studyTime - Available daily study time
  • @motivation - Reason for studying

Context management was used to control the conversation flow and ensure that each response was relevant to the user's current stage.

Personalized Study Planning

The chatbot uses collected user information to provide subject-specific guidance and visual study schedules for Math, Science, Programming, English, and History.

  • Personalized recommendations based on user input
  • Visual study schedules embedded using Dialogflow custom payloads
  • Supportive responses designed to encourage consistency and motivation

Technical Implementation

  • Conversational AI development using Google Dialogflow
  • Intent and entity recognition
  • Slot filling and information extraction
  • Context and conversation-state management
  • Custom payload integration for visual content
  • Interactive chatbot UX with chips, small talk, and fallback handling

Limitations & Future Improvements

  • Currently supports a limited number of academic subjects
  • No long-term user progress tracking
  • Limited integration with external learning resources
  • Future development could include progress tracking, learning-resource links, and broader subject coverage

Reflection

This project strengthened my understanding of conversational AI, intent and entity design, slot filling, and context management. It also demonstrated how AI-powered interfaces can be designed around a specific user problem while balancing technical functionality with usability and engagement.

Olist E-commerce Analytics Dashboard

SQL • MySQL • Power BI • Business Intelligence

MySQL SQL Power BI DAX Power Query Window Functions Business Intelligence

Project Overview

Developed an end-to-end business intelligence project using the Brazilian Olist E-commerce dataset containing 99,441 marketplace orders. The project transformed raw relational data into business insights through SQL analysis, data validation, customer segmentation, cohort retention analysis, and an interactive four-page Power BI dashboard.

Business Objectives

  • Analyse customer purchasing behaviour and marketplace performance
  • Validate relational data quality before analysis
  • Develop business KPIs for decision-making
  • Build an interactive dashboard for business reporting

Dataset & Validation

  • Brazilian Olist E-Commerce Public Dataset (September 2016 - August 2018)
  • 99,441 orders, 96,096 customers, 112,650 order items
  • Validated table relationships and referential integrity before analysis
  • Documented source-data limitations and their impact on reporting
  • Excluded unmatched product records from category analysis while preserving headline KPIs

SQL Analysis & Implementation

  • Developed analytical SQL scripts covering exploration, validation, KPI development, business analysis, and cohort retention
  • Applied Common Table Expressions (CTEs), Window Functions, Subqueries, Aggregations, and Multi-table Joins
  • Used RANK(), ROW_NUMBER(), LAG(), NTILE(), and cumulative SUM() OVER() functions
  • Created reusable analytical SQL views to support Power BI reporting

Dashboard Development

  • Designed a four-page interactive Power BI dashboard:
    • Executive Overview
    • Customer Analysis
    • Products & Sellers Analysis
    • Delivery Performance Analysis
  • Developed DAX measures and Power Query transformations for reporting.

Key Business Insights

  • Identified that approximately 96.88% of customers made only one purchase
  • Analysed customer retention through monthly cohort analysis
  • Identified that the top 10 sellers, representing just 0.3% of all sellers, contributed 13.15% of total item revenue.
  • Observed seasonal sales growth during the November Black Friday period
  • Evaluated delivery performance across Brazilian states, identifying Ceará as the state with the highest late-delivery rate (~14%) and São Paulo as one of the lowest (under 5%) despite having the highest order volume.

Technical Skills Demonstrated

  • Advanced SQL querying
  • Data validation and quality assurance
  • Business KPI development
  • Customer spend segmentation and cohort analysis
  • Window Functions for analytical reporting
  • Power BI dashboard development
  • Business insight communication through data visualisation

Reflection

This project strengthened my understanding of the complete business intelligence workflow, from validating relational datasets and developing analytical SQL solutions to designing interactive dashboards that communicate meaningful business insights. It reinforced the importance of data quality, analytical reasoning, and presenting data in a way that supports informed decision-making.
