Weather Image Classification

CNN & Transfer Learning • Python • TensorFlow • Gradio

Python TensorFlow CNN MobileNetV2 Transfer Learning Gradio Data Preprocessing

Project Overview

Developed a computer vision system to automatically classify weather conditions from images into four categories: Cloudy, Rainy, Shine, and Sunrise. The project demonstrates end-to-end workflow from dataset preprocessing, model training, evaluation, to interactive deployment, showcasing practical AI application skills.

Problem & Objectives

  • Automate detection of weather conditions from outdoor images
  • Handle visually similar categories and small dataset limitations
  • Leverage transfer learning to improve accuracy
  • Deploy an interactive, user-friendly interface for real-time predictions

Dataset & Preprocessing

  • Kaggle multi-class weather image dataset
  • 4 labeled classes: Cloudy, Rainy, Shine, Sunrise
  • Image resizing, normalization, and pixel value scaling
  • Data augmentation: rotation, flipping, zoom for robustness
  • Training/validation split with stratification for class balance

Model Development & Implementation

  • Built a baseline CNN to benchmark performance
  • Applied transfer learning with MobileNetV2 (ImageNet pretrained)
  • Trained custom classification layers while freezing base layers initially
  • Fine-tuned deeper convolutional layers with reduced learning rate
  • Hyperparameter experimentation: batch size, dropout, learning rate, optimizer choice

Evaluation & Results

  • Monitored performance using accuracy, loss curves, and confusion matrix
  • Calculated Precision, Recall, and F1-Score for each class
  • The final MobileNetV2 model achieved 92% validation accuracy and improved classification performance compared to the baseline CNN.
  • Some confusion between Shine and Cloudy, highlighting dataset challenges
  • Implemented iterative improvements based on evaluation insights

Deployment & Application

Deployed the trained model with a Gradio interface allowing users to upload weather images and receive real-time predictions with confidence scores. This demonstrates full-stack deployment skills and user-oriented AI applications.

Key Learning & Skills Demonstrated

  • End-to-end computer vision project development from dataset preprocessing to deployment
  • Practical experience in CNNs, transfer learning, and fine-tuning pretrained models
  • Model evaluation using metrics and confusion matrix for actionable insights
  • Data augmentation techniques to improve model generalization
  • Deployment of machine learning models with interactive user interfaces
  • Problem-solving for small datasets, visually similar classes, and performance optimization

Reflection

This project strengthened my ability to apply deep learning to real-world problems, enhanced my understanding of model evaluation, and demonstrated how to deliver functional AI solutions that are both accurate and user-friendly. I learned to balance technical implementation with usability and performance optimization.

Movio - Data Driven Movie Application

Python Tkinter GUI • MovieDB API Integration

Python Tkinter API Integration Requests GUI Design Threading

Project Overview

Movio is a data-driven desktop application built using Python Tkinter that allows users to explore movies, genres, and popular actors by retrieving real-time data from the Movie Database (TMDB) API. The application provides an interactive graphical interface where users can search for movies, browse popular people, and explore film genres through an organized multi-page navigation system.

Key Features

  • Real-time movie data retrieved using the MovieDB API
  • Search functionality for movies and popular actors
  • Genre-based movie browsing
  • Multi-page GUI navigation system
  • Scrollable content frames for displaying results
  • Interactive welcome page and side navigation panel

Technologies & Libraries

  • Python Tkinter for GUI development
  • Requests library for API communication
  • PIL (Image & ImageTk) for image rendering
  • Threading for background tasks
  • BytesIO for handling image data in memory

System Design

  • Multi-frame architecture for navigation (Search, Genre, People, About)
  • Scrollable frames for large datasets
  • Dynamic image loading for movie posters and actor images
  • Consistent UI layout for improved usability

Error Handling & Robustness

  • Handles API request failures using RequestException
  • Fallback values for missing movie data
  • Placeholder images used when poster retrieval fails
  • Messagebox alerts when search results are empty

Development Approach

The application was developed using an iterative eight-day development plan including design planning, API integration, GUI development, feature implementation, testing, debugging, and final documentation. Wireframes and flowcharts were created to structure the application layout and navigation flow before implementation.

Key Learning

This project strengthened my understanding of API-driven applications, GUI design using Python Tkinter, asynchronous data handling, and structuring multi-page desktop applications. It also improved my ability to design user-friendly interfaces while integrating real-time external data sources.

Bookify - Full Stack Book Discovery Platform

MERN Stack Web Application • API Integration • User Authentication

React Node.js Express MongoDB JWT Auth Google OAuth REST APIs

Project Overview

Bookify is a full-stack book discovery platform that aggregates book information, literary news, and bestseller lists into a unified user experience. The application integrates multiple APIs and allows users to discover books, explore genres, and manage their personal favourites through a secure account system.

Core Features

  • User authentication using Email/Password and Google OAuth
  • Personal Bookshelf where users can save favourite books
  • Featured Books carousel managed through admin CRUD operations
  • Book discovery via search and genre filtering
  • Responsive UI with carousels, modals and animations

API Integrations

  • Google Books API - fetch detailed book metadata
  • New York Times API - display bestseller lists
  • The Guardian API - retrieve book related news

System Architecture

  • Frontend built with React and component-based architecture
  • Node.js and Express REST API for backend services
  • MongoDB Atlas database storing users and featured books
  • JWT authentication securing protected routes
  • MVC-inspired backend structure for scalability

Database Design

  • Users Collection: authentication details and favourites list
  • FeaturedBooks Collection: book metadata used in homepage carousel
  • Schema designed to support scalable content management

Deployment

  • Frontend deployed on Vercel
  • Backend deployed on Render
  • Environment variables used to protect API keys and secrets
  • Cross-origin requests configured for secure communication

Key Learning

This project strengthened my full-stack development skills including API integration, secure authentication, database design and cloud deployment. It also highlighted the importance of error handling, performance optimisation and scalable architecture when building real-world web applications.

Classification Task - Online Purchase Prediction

Machine Learning Classification • Python • EDA & Model Evaluation

Python Pandas NumPy Scikit-learn Logistic Regression KNN Decision Trees Random Forest EDA & Visualization

Project Overview

This project focused on predicting whether an online user would make a purchase. The workflow covered dataset exploration, preprocessing, EDA, model selection, hyperparameter tuning, evaluation, and reflection on model performance and limitations.

Data Preprocessing

  • Encoded categorical features, scaled numerical variables, standardized Boolean attributes
  • Handled class imbalance via oversampling to improve model fairness and accuracy
  • Ensured consistent input formats across models for reliable performance
  • Demonstrated understanding of preprocessing as a critical step in ML workflows

Exploratory Data Analysis (EDA)

  • Visualized user behavior patterns to guide feature selection and hypothesis formation
  • Observed correlations, e.g., more time on product pages linked to purchases
  • Identified non-purchase indicators like high bounce and exit rates
  • Used graphical insights to inform preprocessing and model choices

Model Development & Evaluation

  • Applied multiple models: Logistic Regression, K-Nearest Neighbors, Decision Trees, Random Forests
  • Linear models prioritized interpretability; tree-based models captured non-linear interactions
  • Hyperparameter tuning balanced generalization and overfitting
  • Random Forest achieved highest F1-score, demonstrating practical benefits of ensemble learning
  • Learned trade-offs between accuracy and interpretability in real-world scenarios

Critical Reflection & Skills Demonstrated

  • Structured approach from data exploration to model evaluation
  • Addressed class imbalance and preprocessing challenges
  • Used EDA to inform feature engineering and model selection
  • Experience with multiple modeling techniques and hyperparameter tuning
  • Refined understanding of real-world trade-offs between interpretability and predictive performance
  • Confidence in converting exploratory findings into robust and practical classification models
